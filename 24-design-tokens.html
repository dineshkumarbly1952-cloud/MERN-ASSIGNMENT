Design Tokens Architecture

Bridging Design Systems and CSS Custom Properties for Scalable Web Applications

What are Design Tokens?

Design tokens are the visual design building blocks of a design system—storing atomic values such as color hex codes, spacing increments, font sizes, and border radii. Instead of hardcoding values directly into stylesheets, design tokens act as a single source of truth across design tools (like Figma) and production codebases.

Primitive vs. Semantic Tokens

A robust design token architecture typically separates values into two distinct layers: Primitive Tokens (raw foundational values) and Semantic Tokens (contextual aliases).

Summary of Design Token Layers
Layer Example Variable Purpose / Definition
Primitive --token-blue-500: #2563eb; Stores raw, uncontextualized values (color scales, exact pixel sizes).
Semantic --accent-color: var(--token-blue-500); Assigns meaning and context (e.g., interactive elements, primary branding).

CSS Custom Properties Implementation

Below is how design tokens are structured in practice using native CSS `:root` custom properties:

:root {
  /* Primitive Tokens */
  --token-slate-900: #0f172a;
  --token-blue-500: #2563eb;
  --space-md: 1rem;

  /* Semantic Aliases */
  --primary-color: var(--token-slate-900);
  --accent-color: var(--token-blue-500);
  --card-padding: var(--space-md);
}

Key Benefits of Design Tokens

Implementing a tokenized stylesheet ensures effortless theme switching (such as dark mode support), maintains brand consistency across multi-page portals, and drastically simplifies long-term maintenance when design guidelines evolve.
