CSS Selector Types & Specificity

A Master Reference for Targeting DOM Elements and Calculating Rule Priority

Introduction to CSS Selectors

CSS selectors are the foundational patterns used to select and style elements within an HTML document. Understanding the various selector categories—ranging from simple element names to complex pseudo-classes and combinators—allows developers to write clean, highly maintainable stylesheets without unnecessary rule overrides.

Primary Selector Categories

Summary of core CSS selector types, syntax examples, and descriptions
Selector Type Example Syntax Description
Universal Selector * { margin: 0; } Matches any element in the document tree.
Type / Element Selector p { line-height: 1.6; } Matches all HTML elements of the specified tag name.
Class Selector .card-bg { background: #fff; } Matches all elements containing the specified class attribute value.
ID Selector #main-header { padding: 1rem; } Matches a single unique element possessing the matching ID attribute.
Attribute Selector input[type="text"] { width: 100%; } Matches elements based on the presence or value of an attribute.
Pseudo-Class a:hover { color: #2563eb; } Matches elements based on a specific state or structural position.

Practical CSS Code Sample

Below is a clean example showcasing multiple selector types working together in a structured stylesheet:

/* Type Selector */
body { font-family: sans-serif; color: #334155; }

/* Class Selector */
.content-card { background: #ffffff; border: 1px solid #cbd5e1; }

/* ID Selector */
#overview { margin-bottom: 2rem; }

/* Attribute & Pseudo-Class */
a[target="_blank"]:hover { text-decoration: underline; }

Best Practices

Keep selectors as flat and specific as necessary. Over-relying on high-specificity IDs or deeply nested descendant combinators makes stylesheets rigid and difficult to debug over time.
