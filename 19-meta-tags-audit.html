Meta Tags Audit Checklist

Essential document header tags for search optimization, mobile responsiveness, and social preview cards.

Critical Header Tags

Summary of mandatory HTML head meta elements
Tag Name / Property Category Purpose
<meta charset="UTF-8"> Critical Specifies the character encoding for the document to prevent text display bugs.
<meta name="viewport"> Critical Ensures proper responsive scale and layout on mobile devices.
<title> Critical Defines page title displayed in browser tabs and search engine results (SERP).
<meta name="description"> Recommended Provides concise page summary used in search result snippets.

Social Graph Protocol Tags

Summary of Open Graph and Twitter card properties
Property Platform Function
og:title / twitter:title Facebook / X Title displayed when the link is shared on social platforms.
og:description Facebook / X Summary description for shared link cards.
og:image / twitter:image Facebook / X Preview thumbnail image URL displayed on social feeds.
twitter:card X (Twitter) Card layout type (e.g., summary_large_image).
